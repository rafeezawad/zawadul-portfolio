MEASUREMENT / INSTRUMENTATION

Determination of Applied Force Using Force Sensitive Resistor

A sensor-based instrumentation project using an FSR, µA741 signal conditioning and LM3914 LED bar-graph output.

FSRSEN-0057µA741LM3914Instrumentation

COURSE

EEE-2212 — Measurement and Instrumentation Laboratory

SENSOR

FSR SEN-0057

FORCE RANGE

0.1 N – 10 N

OUTPUT

10-Level LED Bar Graph

01 / OVERVIEW

Project Overview

A force-measurement instrumentation system using a Force Sensitive Resistor. The changing FSR resistance is conditioned through a µA741 stage and displayed as a 10-level LED indication using the LM3914.

05 / SENSOR PRINCIPLE

FSR Operation

Applying force increases contact within the sensor's conductive/resistive layers, causing resistance to decrease. The project report specifies an approximate force sensitivity range of 0.1 N to 10 N.

06 / WORKING PRINCIPLE

Complete System Operation

01

Apply force to the FSR.

02

FSR resistance decreases.

03

Input voltage changes at the amplifier network.

04

Reference voltage remains fixed.

05

µA741 produces a conditioned output.

06

LM3914 receives the conditioned voltage.

07

More LEDs illuminate as force increases.

07 / OUTPUT

LED Force-Level Indication

The LM3914 operates in bar mode, illuminating progressively more LEDs as the applied force increases.
