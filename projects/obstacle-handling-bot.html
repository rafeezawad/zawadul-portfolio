ROBOTICS / EMBEDDED SYSTEMS

Obstacle Detecting & Object Handling Bot

An autonomous Arduino-based mobile robot designed to detect obstacles, evaluate its surroundings and perform object-handling operations using a servo-controlled robotic arm and gripper.

Arduino Uno HC-SR04 L298N SG90 MG996R Embedded Programming

PROJECT TYPE

Open-Ended Lab Project

COURSE

CORE AREA

Robotics, Embedded Systems & Automation

MY PRIMARY ROLE

Arduino Programming Lead & Bot Development

01 / OVERVIEW

Project Overview

The project demonstrates a small-scale autonomous robotic system capable of combining mobility, obstacle detection and physical object manipulation.

The robot moves through its environment while an ultrasonic sensor continuously monitors the path ahead. When an obstacle is detected, the robot stops and uses sensor scanning to evaluate its surroundings.

A robotic arm and gripper mechanism then allows the system to grip, lift, transport and release an object into a designated location.

03 / OBJECTIVES

Project Objectives

  • Design a mobile robot capable of automatically detecting obstacles.
  • Develop a robotic arm capable of gripping and releasing objects.
  • Program the robot using Arduino for autonomous operation.
  • Demonstrate the principles of a simplified pick-and-place robotic system.

04 / HARDWARE

Components Used

Arduino Uno Main microcontroller responsible for system decision-making and control.
HC-SR04 Ultrasonic Sensor Measures distance and detects obstacles in the robot's path.
L298N Motor Driver Controls the motors responsible for robot movement.
MG996R Servo Motor High-torque servo used within the robotic arm mechanism.
SG90 Servo Motor Used for servo-controlled movement and sensor or gripper mechanisms.
Gripper Mechanism Responsible for gripping and releasing objects.
Chassis & Wheels Provides the physical mobile platform.
9–12 V Battery Supply Provides power for the motors and electronic system.

05 / WORKING PRINCIPLE

How the Robot Works

01

The robot begins by moving forward.

02

The HC-SR04 ultrasonic sensor continuously scans the path ahead.

03

When an obstacle is detected within approximately 15 cm, the robot stops.

04

The ultrasonic sensor mounted on a servo rotates left and right to scan the surrounding path.

05

The control logic evaluates the scan and determines the clearer direction.

06

The robotic arm lowers and grips the object using the servo-controlled gripper.

07

The robotic arm lifts the object.

08

The robot moves toward the designated drop zone.

09

The gripper releases the object into the designated box.

10

The arm returns to its initial position and the operating cycle continues.

06 / PROGRAMMING

Arduino Control Logic

The Arduino Uno was programmed using the Arduino IDE. The program integrates distance measurement, motor control, servo operation and autonomous condition-based decision logic.

  • Distance measurement using the HC-SR04 ultrasonic sensor
  • Forward, backward, left, right and stop motor commands
  • Robotic-arm servo control
  • Gripper opening and closing
  • Ultrasonic sensor directional scanning
  • Condition-based autonomous decision logic

07 / RESULTS

Results

  • The robot successfully detected obstacles within the intended 15 cm range.
  • The robotic arm successfully picked up and released objects.
  • Ultrasonic scanning enabled the robot to evaluate direction before movement.
  • Testing on classroom and laboratory floors produced consistent results.
