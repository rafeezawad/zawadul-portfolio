DIGITAL ELECTRONICS / SEQUENTIAL LOGIC

Digital Voting System Using Sequential Logic Circuits

A digital electronics project designed to register, count, display and compare votes using sequential logic circuits, counters, BCD decoding and comparator logic.

74LS90 74LS47 74LS83 74HC85 Seven-Segment Display Sequential Logic

COURSE

EEE 3104 — Digital Electronics-1 Lab

PROJECT TYPE

Open-Ended Lab Project

CORE AREA

Sequential Logic & Digital Electronics

SUPPLY

5 V DC

01 / OVERVIEW

Project Overview

The digital voting system was designed using sequential logic circuits to register votes for multiple candidates and display the vote counts in real time.

The system combines decade counters, BCD-to-seven- segment decoding and comparator logic to provide accurate vote counting and candidate comparison.

02 / OBJECTIVES

Project Objectives

  • Design a digital voting system using logic circuits.
  • Implement an independent vote counting mechanism for each candidate.
  • Display vote counts using seven-segment displays.
  • Prevent erroneous multiple counts using switch debouncing.

03 / HARDWARE

Components Used

74LS90 Decade Counter Counts each candidate's votes and outputs the count in BCD format.
74LS47 BCD Decoder Converts BCD counter output into seven-segment display signals.
74LS83 4-bit Binary Adder Provides binary addition functionality within the digital logic design.
74HC85 4-bit Comparator Compares candidate vote counts and supports identification of the highest vote count.
Seven-Segment Displays Display the vote totals in decimal form.
Push-Button Switches Used by voters to register votes for individual candidates.
LEDs Provide visual status indication.
Resistors & Capacitors Used for supporting circuit operation and switch debouncing.

04 / WORKING PRINCIPLE

System Operation

01

A voter presses the push-button corresponding to a selected candidate.

02

The switch input is debounced to prevent false multiple vote registrations.

03

A clock pulse is sent to the corresponding 74LS90 decade counter.

04

The counter increments the candidate's vote count and outputs the result in BCD format.

05

The BCD output is fed into the 74LS47 decoder.

06

The seven-segment display shows the candidate's updated vote count in real time.

07

The 74HC85 comparator compares candidate vote counts to determine the higher count.

05 / OBSERVATIONS

Experimental Observations

  • Votes were registered accurately during testing.
  • Correct vote values were displayed on the seven-segment displays.
  • Switch debouncing prevented multiple false counts.
  • The reset function successfully cleared the counters.
  • Comparator logic successfully identified the highest vote count in real time.

06 / ADVANTAGES

System Advantages

  • Real-time vote counting
  • Simple and reliable circuit design
  • Debounced vote switches
  • Expandable for additional candidates
  • Real-time candidate comparison using 74HC85

07 / LIMITATIONS

Current Limitations

  • No voter authentication is implemented.
  • The current design is limited in scalability by the number of counters and displays.
  • Vote information is not retained after power loss.
  • The design is most suitable for small-scale voting or polling applications.

08 / FUTURE WORK

Future Improvements

  • Add voter authentication.
  • Migrate the design to a microcontroller or FPGA.
  • Add EEPROM or other non-volatile storage for vote retention.
  • Improve scalability for additional candidates.
  • Explore secure remote voting capabilities.
