POWER SYSTEMS / PROTECTION

Overload Detection & Protection System

An Arduino-based electrical protection system designed to continuously monitor load current and automatically isolate the connected load when the measured current exceeds a predefined safe operating threshold.

Arduino Uno ACS712 Relay Protection I²C LCD 700 mA Threshold Power System Protection

COURSE

PROTECTION TYPE

TRIP THRESHOLD

700 mA

CONTROL PLATFORM

Arduino Uno

01 / OVERVIEW

Project Overview

Overload is a common abnormal operating condition in electrical systems. It occurs when the current drawn by a connected load exceeds its rated or safe operating capacity.

Excessive current increases I²R losses and heat generation, which can contribute to insulation degradation, reduced efficiency and equipment failure.

This project demonstrates a practical low-voltage overload protection system that continuously measures load current, evaluates the measured value against a predefined threshold and isolates the load when an overload condition occurs.

03 / HARDWARE

Main Components

ACS712 Current Sensor Hall-effect current sensor used to measure load current and provide an analog output proportional to current.
Arduino Uno Reads the sensor output, calculates current and controls the relay, buzzer and display.
Relays Electrically isolate the connected load during an overload condition.
Buzzer Provides an audible indication when a fault is detected.
I²C LCD Display Displays the real-time current value and system operating status.
Transformer Steps down the AC supply voltage to a safer low-voltage level.
1N4007 Diode Used in the power-supply rectification stage.
Filter Capacitor Smooths the rectified DC output and reduces ripple.
7805 Voltage Regulator Provides a regulated 5 V DC supply for the control electronics.
Bulb Load Represents the electrical load used during experimental testing.

04 / WORKING PRINCIPLE

System Operation

01

The transformer steps down the AC voltage, while the diode, capacitor and 7805 regulator provide the required low-voltage DC supply.

02

The ACS712 current sensor continuously measures the current flowing through the connected load.

03

The Arduino reads the sensor's analog signal and calculates the load current using sensor calibration.

04

The measured current is compared with the predefined threshold of 700 mA.

05

When the current remains below the threshold, the system continues normal operation.

06

When current exceeds 700 mA, the system detects an overload fault.

07

Both relays are deactivated to isolate the load, while the buzzer activates and the LCD displays the fault condition.

08

The system remains in a latched fault condition until it is manually restored.

06 / ANALYSIS

Load Current Analysis

The approximate load current was calculated from the relationship between electrical power and supply voltage.

I = P / V

For one 100 W bulb operating from a 220 V supply:

I = 100 / 220 ≈ 0.45 A

For two identical 100 W bulbs:

I = 200 / 220 ≈ 0.91 A

Since the system threshold is 0.7 A, one bulb remains within the normal operating region, while two bulbs exceed the threshold and initiate overload protection.

08 / ADVANTAGES

System Advantages

09 / LIMITATIONS

Current Limitations

  • The current measurement range is limited by the selected sensor rating.
  • The system does not detect short-circuit faults.
  • No time-delay protection is implemented.
  • Fault reset is not automatic.
  • Measurement accuracy depends on sensor calibration.
