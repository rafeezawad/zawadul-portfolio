POWER SYSTEMS / PROTECTION

Overload Detection & Protection System

An Arduino-based protection system using ACS712 current sensing, relay isolation, buzzer indication and real-time LCD monitoring.

Arduino UnoACS712Relay ProtectionI²C LCD700 mA Threshold

COURSE

EEE 4154 — Power System II Lab

PROTECTION

Overload / Overcurrent

TRIP THRESHOLD

700 mA

CONTROL

Arduino Uno

01 / OVERVIEW

Project Overview

A low-voltage overload protection system that continuously measures load current and isolates the load when current exceeds a 700 mA threshold. The Arduino also drives a buzzer and I²C LCD status display.

04 / WORKING PRINCIPLE

Protection Sequence

01

Low-voltage DC supply is produced through transformer, rectifier, filter and regulator.

02

ACS712 measures current in series with the load.

03

Arduino converts the sensor output into a current value.

04

Measured current is compared with the 700 mA threshold.

05

Normal current keeps the system operational and visible on the LCD.

06

Overload deactivates both relays, activates the buzzer and shows a fault message.

07

Fault state remains latched until manual restoration.

05 / CALCULATION

Load Current Analysis

I = P / V

07 / LIMITATIONS

Limitations

  • Current range depends on sensor rating.
  • Short-circuit detection is not implemented.
  • No time-delay protection is implemented.
  • Fault reset is manual.
  • Accuracy depends on sensor calibration.

Future Improvements
